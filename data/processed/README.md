# data/processed

서비스에 보이는 콘텐츠 데이터다. 형식은 `data/schema/`, 설계 이유는 `docs/architecture.md` 1절에 있다.

| 폴더 | 내용 | 누가 채우나 |
|---|---|---|
| `fields/` | 분야와 그 분야의 길 | 기획(A)이 초안, 팀 검토 |
| `steps/` | 여러 길이 함께 쓰는 단계 | 기획(A) |
| `helps/` | 지원·장학금·무료 강의·대회·체험 | 사실 확인(C)이 **공식 공고로 확인한 것만** |
| `redirects.json` | 바뀐 URL | 슬러그를 바꿀 때 |

## 도움(help) 항목 추가하는 법

1. `data/templates/help.example.json`을 복사해 `helps/<id>.json`으로 저장한다.
2. 공식 공고를 보고 채운다. `summary`는 직접 쓴다(원문 복사 금지). `checked_at`에 확인한 날짜를 적는다.
3. `npm run validate`로 검사한 뒤 PR을 올린다.
4. **항목 하나를 모으는 데 걸린 시간**을 PR 설명에 적는다 (1주차에 재는 것).

## 규칙

- ID는 한 번 공개하면 바꾸지 않는다. 없앨 때는 지우지 말고 `"retired": true`를 적는다.
- 개인정보(전화번호, 개인 이메일 등)를 넣지 않는다. 검사가 막는다.

> 상태 (2026-09-26): `cooking` 분야는 **초안**이다. 길과 단계 설명은 팀이 검토하고, `helps/`는 비어 있다.
