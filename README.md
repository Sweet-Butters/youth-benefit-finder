# youth-benefit-finder (가칭)

> **지금 내 자리에서 시작하는 진로**
>
> 진로를 고민하는 청소년이 지금 상황에서 갈 수 있는 여러 길을 알고, **사람과 이야기하며 방향을 찾고**, 필요한 지원까지 이어 가도록 돕는 서비스.
> 사람이 중심이고, AI는 보조한다. 대학은 여러 길 중 하나로 똑같이 다룬다.

## 해결하려는 문제

### 확인된 것 (자료 있음)

- 학교 밖 청소년은 약 **17만 3,800명**(2024년 추정)이고, 매년 5만 명 안팎이 새로 학교를 떠난다.
- 학업을 그만둔 뒤 **가장 큰 어려움은 진로 찾기(26.9%)**다. 새 친구 만들기(26.2%), 의욕 없음(24.6%)이 뒤를 잇는다 (2025 학교 밖 청소년 실태조사).
- 진로 관련 어려움은 **진로 계획을 어떻게 세울지 모름(42.4%)**, **내 적성을 모름(41.2%)**, 진로를 생각하면 불안·답답함(40.9%) 순이다 (2025).
- 학교 밖 청소년 **약 3명 중 1명(31.4%)은 진로를 정하지 못했다** (2025).
- 기존 진로 서비스는 학교 단위로 신청하거나(커리어넷 원격영상 진로멘토링), 지역이 한정되거나(서울 원스톱), 대상 연령이 맞지 않는다(온통청년). → [경쟁 분석](docs/competitors.md)

> 출처: [2025 학교 밖 청소년 실태조사 (아시아경제 2026.4.26)](https://view.asiae.co.kr/article/2026042611450484659), [더나은미래 2026.1.26](https://futurechosun.com/archives/142614)
> 2025 조사 응답자 2,811명 중 2,362명은 센터·쉼터·소년원 등 기관에 이미 연결된 청소년이다.
> 학교에 다니는 청소년과 비교한 자료는 없어서, 학교 밖 청소년이 **특별히** 진로를 못 정하는지는 알 수 없다.

### 아직 가설 (인터뷰로 확인할 것)

- 진로를 같이 고민해 줄 사람, 특히 **여러 길을 간 어른을 만날 기회가 적다.** 근거는 꿈드림 관계자 한 명의 말("센터에서 만나는 어른이 대부분 사회복지사라 진로 인식이 쏠린다")뿐이다.
- 이야기를 나누고 방향이 생기면 **실제로 다음 행동을 한다.**
- AI에게 물어볼 수는 있지만, **사람과 이야기하는 쪽을 더 원한다.**
- 방향이 생겨도 다음 단계(검정고시, 자격증, 직업훈련, 장학금)에 필요한 지원이 흩어져 있어 **혼자 찾기 어렵다.**

> ⚠️ 확인 방법과 판단 기준은 [검증 계획](docs/validation-plan.md)에 있다.

## 대상

- **비전**: 진로를 고민하는 모든 미성년자
- **첫 대상**: 학교 밖 청소년. 챙겨 줄 담임이나 진로교사가 없어 문제가 가장 절실하고, 꿈드림 봉사를 통해 직접 만날 수 있다.

## 핵심 기능

> **MVP는 멘토 연결이 아니다.** 먼저 콘텐츠와 로드맵 도구로 **사람을 모으고**, 사람이 충분히 모이면 진로 대화(멘토)를 붙인다. → [MVP 설계](docs/mvp.md)

### 0. MVP: 콘텐츠 + 로드맵 도구 + 구독
- [ ] 콘텐츠: 직업별 여러 길, 여러 길을 간 사람 이야기, 상황별 선택지 (인스타·쇼츠·웹 글)
- [ ] 로드맵 도구: 질문 5개 → 갈 수 있는 여러 길(마일스톤) + 이번 주 할 일 + 단계별 지원과 대회·활동 (v0는 AI 없이)
- 커리큘럼(강의·교재)은 만들지 않는다. 목표까지의 **지도**를 주고, 가르치는 내용은 이미 있는 곳으로 연결한다.
- [ ] 모으기: **선택 가입**(학생 만 14~24세, 최소 수집, v0부터) + 카카오톡 채널·인스타 팔로우
- [ ] 관심 찾기 퀴즈: 하고 싶은 게 아직 없는 학생에게 해 볼 만한 분야 3개와 가볍게 해 보는 체험 (진단이 아니라 시작점, D14)
- [ ] 고민 Q&A: 익명 고민에 여러 길을 간 사람이 답하는 콘텐츠 (또래 댓글은 사람이 모인 뒤)

### 1. 진로 대화 (서비스의 중심, 사람이 모인 뒤)
- [ ] 진로 분야별 멘토(현직자, 기업 임직원, 대학생)와 1:1 대화
- [ ] 한 번으로 끝나지 않는 꾸준한 만남 (방향 찾기 → 다음 단계 실행까지)
- [ ] 멘토링 활동 기록 → 기업용 임팩트 리포트

> 대화 연결은 처음부터 자동화하지 않는다. 먼저 **꿈드림 선생님을 통해 사람이 직접 연결**하는 방식으로 수요를 확인한 뒤 기능으로 만든다.

### 2. AI 보조 (사람의 대화를 돕는다)
- [ ] **대화 전**: 학생이 자기 고민을 정리하도록 돕는 질문, 학생이 동의하면 멘토에게 요약 전달
- [ ] **대화 후**: 나눈 이야기를 진로 로드맵과 다음 할 일로 정리 (예: 요리사 → 검정고시 → 조리기능사 → 현장 실습)
- [ ] **만남 사이**: 간단한 질문에 답하고, 할 일과 마감을 알려 준다

AI가 하지 않는 것:
- 진로를 **대신 정하지 않는다.** 방향은 학생이 멘토와 이야기하며 정한다.
- 위기 신호(자해, 학대, 극심한 불안 등)가 보이면 대화를 이어가지 않고 **사람(센터 선생님)에게 넘긴다.**
- 대화 내용을 광고나 판매에 쓰지 않는다.

### 3. 실행 지원 (방향이 정해진 뒤)
- [ ] 로드맵 단계별로 받을 수 있는 공공·민간 지원 추천 (교육, 장학금, 직업훈련)
- [ ] 마감 알림, 신청 체크리스트

## 차별점

국내외에서 아래 조합을 모두 하는 서비스는 확인되지 않았다. → [경쟁 분석](docs/competitors.md)

1. 10대 대상 + **사람 중심의 꾸준한 진로 대화** + AI 보조
2. 전국 단위 온라인 멘토 연결 (현재 서울 원스톱서비스만 서울 한정으로 운영)
3. 진로 대화에서 로드맵, 공공·민간 지원 신청까지 한 흐름으로 이어짐

## 동작 방식

### 서비스 흐름

```
[연결]   센터 선생님을 통해 학생과 멘토 연결
   ↓
[준비]   AI가 학생의 고민 정리를 돕는다 (학생 동의 시 멘토에게 요약)
   ↓
[대화]   학생과 멘토가 이야기하며 방향을 찾는다   ← 서비스의 중심
   ↓
[정리]   AI가 로드맵과 다음 할 일로 정리, 필요한 지원 추천
   ↓
[실행]   학생이 신청·준비, 멘토가 다음 만남에서 확인
```

### 지원 정보 수집 (실행 지원용)

```
[수집]   공공데이터 API + 민간 사이트 크롤링
   ↓
[가공]   Jev로 조건 추출 (나이, 지역, 대상, 분야, 마감일)
         일반 LLM으로 요약 생성
   ↓
[저장]   정리된 혜택 데이터 (data/processed)
   ↓
[추천]   사용자 조건과 매칭하여 혜택 추천
   ↓
[연결]   진로 분야에 맞는 멘토 연결 (2단계, 로그인·DB 필요)
```

- 수집·가공은 GitHub Actions로 매일 자동 실행한다.
- 새로 올라오거나 바뀐 공고만 처리해 비용을 줄인다.
- 지원 정보와 로드맵 도구는 가입 없이도 쓸 수 있다. **선택 가입(만 14세 이상)은 v0부터** 넣고, 멘토 대화 기능은 사람이 모인 뒤 도입한다.

## 원칙

### 데이터
- **원문을 그대로 재배포하지 않는다.** 제목, 조건, 마감일, 원문 링크 등 정리된 정보만 제공한다.
- 수집 전 각 사이트의 이용약관과 robots.txt를 확인한다.
- API 키는 `.env`와 GitHub Secrets로만 관리한다.

### 개인정보와 안전 (미성년자 대상)
- 개인정보는 **최소한으로 수집**하며 저장소에 두지 않는다. MVP의 가입은 **학생 트랙 만 14~24세**만 받는다 (만 14세 미만은 보호자 동의가 필요해 나중에 검토). 부모님·선생님·멘토는 **어른 트랙으로 v1에 따로** 만들고, 학생과 같은 공간에 섞지 않는다 (D13).
- **개인을 알아볼 수 있는 청소년 데이터는 판매하거나 광고에 쓰지 않는다.** 개인을 알 수 없게 합친 통계만 리포트로 활용한다 (D10). (참고: 장학금 앱 Scholly는 2023년 Sallie Mae에 인수된 뒤, 2026년 4월 창업자가 "미성년자를 포함한 사용자 데이터를 제대로 알리지 않고 팔았다"며 인수사를 상대로 소송을 냈다. Sallie Mae는 부인하고 있다. [TechCrunch](https://techcrunch.com/2026/04/28/founder-of-shark-tank-backed-startup-scholly-sues-his-acquirer-sallie-mae/))
- 멘토는 신원 확인과 성범죄 경력 조회를 거친다.
- 멘토링 대화는 기록을 보관하고 신고 기능을 둔다. 초기에는 기관(꿈드림 등)을 통해서만 연결한다.
- AI 보조는 학생과 보호자에게 **AI라는 것을 분명히 알린다.** AI와 나눈 대화도 학생 동의 없이 멘토나 센터에 넘기지 않는다. 단, 위기 신호는 예외로 하고 이 원칙을 미리 알린다.

## 로드맵

> 단계별 판단 지점과 일정은 [기획 로드맵](docs/roadmap.md)에 있다.

- [ ] **1단계: 검증 + MVP 시작** — 꿈드림 AI 교육 봉사·인터뷰 (2026년 10~12월), 동시에 콘텐츠 주 2개 발행, 로드맵 도구 v0(선택 가입 포함), 고민 Q&A
- [ ] **2단계: 사람 모으기** — 가입자 + 카톡 채널 + 인스타 팔로워 1,000명 목표 (기준은 팀이 확정), 로드맵 도구에 AI 붙이기 (v1)
- [ ] **3단계: 진로 대화 소규모 시험** — 센터 선생님을 통해 학생과 멘토 5~10쌍 직접 연결. 멘토는 콘텐츠 인터뷰에서 만난 현직자부터
- [ ] **4단계: 실행 지원 확대** — 지원 정보 수동 정리 → 필요해지면 수집 자동화
- [ ] **5단계: 대화 연결 기능 개발** — 멘토 계정과 검증, 대화 기록, 신고, 또래 댓글(안전장치와 함께)
- [ ] **6단계: 임팩트 측정과 수익화** — 대화 → 실제 행동 추적, 기업용 임팩트 리포트
