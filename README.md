# youth-benefit-finder (가칭)

> 진로 목표에 맞춰, 청소년이 받을 수 있는 공공·민간 혜택과 지원을 한곳에 모아 보여주는 서비스

## 해결하려는 문제

- 학교 밖 청소년을 포함한 미성년자를 위한 지원(교육, 장학금, 직업훈련, 멘토링 등)은 많지만, 정부·지자체·재단·민간 단체에 흩어져 있다.
- 기존 서비스는 대상 연령이 맞지 않거나(예: 청년 정책은 19~34세), 공공 혜택만 다루거나, 진로와 연결되지 않는다.
- 그 결과, 정보를 찾지 못해 받을 수 있는 지원을 놓치는 청소년이 생긴다.

## 핵심 기능 (계획)

- [ ] **맞춤 질문**: 나이, 지역, 재학·학교 밖 여부, 관심 분야 입력
- [ ] **진로 로드맵**: 목표 직업까지의 단계 제시 (예: 요리사 → 검정고시 → 조리기능사 → 현장 실습)
- [ ] **단계별 혜택 추천**: 공공·민간 구분 없이 조건에 맞는 지원 표시
- [ ] **마감 알림 및 신청 체크리스트**

## 동작 방식

```
[수집]  공공데이터 API + 민간 사이트 크롤링
   ↓
[가공]  Jev로 조건 추출 (나이, 지역, 대상, 분야, 마감일)
        일반 LLM으로 요약 생성
   ↓
[저장]  정리된 혜택 데이터 (data/processed)
   ↓
[서비스] 웹에서 사용자 조건과 매칭하여 추천
```

- 수집·가공은 GitHub Actions로 매일 자동 실행한다.
- 새로 올라오거나 바뀐 공고만 처리해 비용을 줄인다.

## 데이터 원칙

- **원문을 그대로 재배포하지 않는다.** 제목, 조건, 마감일, 원문 링크 등 정리된 정보만 제공한다.
- 수집 전 각 사이트의 이용약관과 robots.txt를 확인한다.
- **사용자 개인정보는 최소한으로 수집**하며 저장소에 두지 않는다. 만 14세 미만은 보호자 동의 절차를 따른다.
- API 키는 `.env`와 GitHub Secrets로만 관리한다.
