# youth-benefit-finder (가칭)

> 진로 목표에 맞춰, 청소년이 받을 수 있는 공공·민간 혜택을 찾아주고 도와줄 수 있는 사람과 연결해 주는 서비스

## 해결하려는 문제

- 미성년자를 위한 지원(교육, 장학금, 직업훈련, 멘토링 등)은 많지만, 정부·지자체·재단·기업·민간 단체에 흩어져 있다.
- 기존 서비스는 대상 연령이 맞지 않거나(예: 청년 정책은 19~34세), 공공 혜택만 다루거나, 진로와 연결되지 않는다.
- 기업 장학금 같은 민간 혜택은 뉴스나 센터 공지로만 퍼져서 놓치기 쉽다.
- 정보를 알아도 혼자서는 움직이기 어렵다. 옆에서 도와줄 사람이 필요하다.

> ⚠️ 위 문제는 아직 **가설**이다. 당사자 인터뷰로 검증 중이다. → [검증 계획](docs/validation-plan.md)

## 대상

- **비전**: 진로를 고민하는 모든 미성년자
- **첫 대상**: 학교 밖 청소년. 챙겨 줄 담임이나 진로교사가 없어 문제가 가장 절실하고, 꿈드림 봉사를 통해 직접 만날 수 있다.

## 핵심 기능

### 1. 혜택 찾기 (무료, 사용자를 모으는 입구)
- [ ] 맞춤 질문: 나이, 지역, 재학·학교 밖 여부, 진로 목표
- [ ] 진로 로드맵: 목표까지의 단계 제시 (예: 요리사 → 검정고시 → 조리기능사 → 현장 실습)
- [ ] 단계별 혜택 추천: 공공·민간 구분 없이 조건에 맞는 지원
- [ ] 마감 알림, 신청 체크리스트

### 2. 사람 매칭 (수익이 나오는 곳)
- [ ] 진로 분야별 멘토(현직자, 기업 임직원, 대학생) 연결
- [ ] 혜택 추천에서 멘토 연결로 이어지는 흐름 (예: 조리 훈련·장학금 추천 → 현직 셰프 멘토)
- [ ] 멘토링 활동 기록 → 기업용 임팩트 리포트

> 매칭은 처음부터 자동화하지 않는다. 먼저 **꿈드림 선생님을 통해 사람이 직접 연결**하는 방식으로 수요를 확인한 뒤 기능으로 만든다.

## 차별점

국내외에서 아래 조합을 모두 하는 서비스는 확인되지 않았다. → [경쟁 분석](docs/competitors.md)

1. 10대 대상 + 공공·민간 혜택 통합 + 진로 목표 기반 추천
2. 전국 단위 온라인 멘토 매칭 (현재 서울 원스톱서비스만 서울 한정으로 운영)
3. 혜택 추천과 멘토 연결이 한 흐름으로 이어짐

## 수익 모델 (가설)

청소년에게는 돈을 받지 않는다. 청소년 데이터를 팔지 않는다.

| 모델 | 누가 내나 | 참고 사례 |
|---|---|---|
| 기업 사회공헌 + 임팩트 리포트 | 임직원 멘토 봉사를 운영하려는 기업 | CareerVillage, 사단법인 점프 |
| B2G | 지자체, 꿈드림 센터 | 웰로의 지자체 입점 |
| 기관 구독 | 학교, 진로교사, 상담기관 | iMentor, 코멘토 대학 제휴 |
| 기업 장학금 설계 대행 | 장학 사업을 하려는 기업 | 드림스폰 콜라보 장학금 |

## 동작 방식

```
[수집]   공공데이터 API + 민간 사이트 크롤링
   ↓
[가공]   Jev로 조건 추출 (나이, 지역, 대상, 분야, 마감일)
         일반 LLM으로 요약 생성
   ↓
[저장]   정리된 혜택 데이터 (data/processed)
   ↓
[추천]   사용자 조건과 매칭하여 혜택 추천
   ↓
[연결]   진로 분야에 맞는 멘토 연결 (2단계, 로그인·DB 필요)
```

- 수집·가공은 GitHub Actions로 매일 자동 실행한다.
- 새로 올라오거나 바뀐 공고만 처리해 비용을 줄인다.
- 혜택 찾기는 로그인 없이 쓸 수 있게 한다. 로그인과 데이터베이스는 매칭 단계에서 도입한다.

## 원칙

### 데이터
- **원문을 그대로 재배포하지 않는다.** 제목, 조건, 마감일, 원문 링크 등 정리된 정보만 제공한다.
- 수집 전 각 사이트의 이용약관과 robots.txt를 확인한다.
- API 키는 `.env`와 GitHub Secrets로만 관리한다.

### 개인정보와 안전 (미성년자 대상)
- 개인정보는 **최소한으로 수집**하며 저장소에 두지 않는다. 만 14세 미만은 보호자 동의를 받는다.
- **청소년 데이터를 판매하거나 광고에 쓰지 않는다.** (참고: 장학금 앱 Scholly는 인수 후 사용자 데이터 판매 의혹으로 소송 중)
- 멘토는 신원 확인과 성범죄 경력 조회를 거친다.
- 멘토링 대화는 기록을 보관하고 신고 기능을 둔다. 초기에는 기관(꿈드림 등)을 통해서만 연결한다.

## 로드맵

> 단계별 판단 지점과 일정은 [기획 로드맵](docs/roadmap.md)에 있다.

- [ ] **1단계: 문제 검증** — 꿈드림 AI 교육 봉사 (2026년 10~12월) + 당사자 인터뷰
- [ ] **2단계: 혜택 찾기 MVP** — 수동 정리 혜택 30~50개 + 진로 질문 기반 추천 페이지
- [ ] **3단계: 사람 매칭 수동 시험** — 꿈드림 선생님을 통해 멘토 직접 연결
- [ ] **4단계: 데이터 자동화** — 공공데이터 API, 민간 크롤러 2~3곳, Jev 조건 추출, 실패 알림
- [ ] **5단계: 매칭 기능 개발** — 로그인, 멘토 검증, 대화 기록, 신고
- [ ] **6단계: 임팩트 측정과 수익화** — 추천 → 신청 추적, 기업용 임팩트 리포트
