# 자금 조달 조사

> 조사일: 2026-09-25 (웹 검색 기반). **2027년 일정은 2026년 공고를 보고 짐작한 것**이다. 지원 전에 반드시 실제 공고를 확인한다.
> 결론: 이 프로젝트에 맞는 공모·지원사업은 대부분 **봄(3~6월)**에 열린다. 2026년 10~12월은 **근거를 쌓는 기간**으로 쓰고, 2027년 봄에 지원한다.

## 요약

| 시기 | 할 일 |
|---|---|
| 2026년 10~12월 | 인터뷰 결과, 콘텐츠 반응, 로드맵 도구 사용 수 같은 **근거 쌓기**. 학교 창업지원단 프로그램 확인 |
| 2026년 12월~2027년 1월 | 연세대 캠퍼스타운 에스큐브 입주 모집 확인 (1월 예상) |
| 2027년 3~4월 | **사회적기업가 육성사업** 지원 (가장 중요) |
| 2027년 6월 | 백암재단 공모전 (작지만 연습 삼아) |
| 콘텐츠가 쌓이고 팔로워가 모인 뒤 | 텀블벅 책 펀딩 검토 |

## 1. 2026년 10월 이후 열려 있는 것

조사한 범위에서는 **잘 맞는 것을 찾지 못했다.**

- **KOICA 2026 인도적 지원 청년·대학생 아이디어 경진대회**: 10월 11일까지 접수. 주제가 해외 인도적 지원이라 이 프로젝트와 맞지 않는다. ([뉴스와이어](https://www.newswire.co.kr/newsRead.php?no=1042703))
- 화성시 소셜벤처 창업 아이디어 경진대회, 제10회 소셜벤처 혁신경연대회 등은 10월에 심사·발표가 있지만 **접수는 여름에 끝났다.**
- **직접 확인할 것**: 연세대·서강대 창업지원단의 하반기 교내 프로그램. 학교 프로그램은 가을에도 열리는 경우가 많은데, 이번 조사에서는 확인하지 못했다. ([연세대 창업지원단](https://venture.yonsei.ac.kr/))

### 알아 둘 것

- **사업자 없이 지원 가능한 것**: 사회적기업가 육성사업, 예비창업패키지 같은 창업 지원사업은 예비창업자(팀)로 지원할 수 있다.
- **조직이 필요한 것**: 예비사회적기업 지정은 법인이나 단체가 있어야 한다. 나중 단계다.
- **지역 조건**: 구청·시청 대회는 거주지나 학교 소재지 조건이 붙는 경우가 많다.

## 3. 텀블벅 (크라우드펀딩)

- "서비스를 만들 돈"으로는 어렵다. 텀블벅은 후원자가 **선물(리워드)**을 받는 창작 프로젝트 중심이다. 순수 기부형이 가능한지는 **텀블벅 가이드로 다시 확인**해야 한다.
- **해 볼 만한 형태**: 콘텐츠를 책으로 만든 《지금 내 자리에서 시작하는 진로 길 지도》 + "한 권 사면 한 권은 꿈드림 센터에" 기부.
- **시기**: 팔로워가 수백 명 모인 뒤 (예: 2027년 봄 이후). 펀딩은 이미 우리를 아는 사람이 있어야 성공하는 경우가 많다.
- **주의**: 인쇄·배송 책임, 해마다 바뀌는 정보는 책에 넣지 않기, 사람 이야기의 본인·보호자 동의, 세금·정산 방식(개인 또는 사업자).
- 기관 기부 플랫폼(해피빈, 같이가치 등)은 보통 **등록된 비영리 단체**만 쓸 수 있다.

## 4. 지원서를 위해 지금부터 모을 근거

봄 지원사업은 "문제를 확인했는가"와 "초기 반응이 있는가"를 본다. 가을에 아래를 기록해 둔다.

- 인터뷰 결과 요약 (청소년 10명 이상, 선생님 3명 이상, 개인을 알아볼 수 없게)
- 콘텐츠 반응: 조회수, 팔로워·카톡 채널 친구 수, 다시 찾아온 비율
- 로드맵 도구 사용 수, 많이 고른 분야
- 봉사 수업 운영 횟수와 참여 학생 수
- 센터 선생님의 의견 (허락받은 범위에서)
