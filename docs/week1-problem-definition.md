# 1주차 미션: 문제/니즈 정의

> 작성일: 2026-09-25. 동아리 1주차 미션 양식(데스크리서치 → 문제 명확화 → 기존 솔루션 분석 → 최종 문제 정의 → MISSION)에 맞춰 정리한 내용이다.
> 슬라이드(PPT)는 이 문서를 바탕으로 만든다. **PPT의 MISSION 문장에는 수치를 넣지 않는다.** 수치가 들어간 버전은 근거를 기억하기 위해 이 문서에만 남긴다.
> 수치는 모두 확인한 출처가 있다. 가설인 부분은 **(가설)**로 표시했다.
> 팀명: **Team 유이정**. PPT 파일은 저장소 밖(팀 공유 폴더)에 둔다.

### 논문 / 칼럼

**1. 임한려·홍성표 (2021). 학교 밖 청소년의 진로탐색활동이 학업 및 직업 활동 참여에 미치는 영향 분석. 진로교육연구, 34(2), 69-91.**
- 대상: 한국청소년정책연구원 학업중단청소년패널 2~5차년도, 17세 이상 학교 밖 청소년 262명
- 진로탐색활동 수준은 평균 1.92점으로 낮았다.
- 참여하지 않던 청소년의 **48.24%는 계속 참여하지 않았다.**
- 진로탐색활동이 1단위 늘면 학업·직업 활동에 참여할 가능성이 **2.002배** 높아졌다.
- 의미: 직접 해 보는 진로 탐색이 다음 행동으로 이어진다 → 관심 찾기 퀴즈·체험(D14)의 근거. 참여하지 않는 청소년은 계속 참여하지 않는 경향도 보인다.
- 출처: [KCI](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002732135)

**2. 한국청소년정책연구원 (2025). 학교 밖 청소년 진로 지원을 위한 다체계 연계 지원 방안 연구 (연구책임 김성은).** 뉴스핌 2026.4.8 보도
- **69.5%는 진로 계획을 세운 적이 있고, 90.9%는 지금 하고 있는 일이 있다.**
- 진로를 정하지 않고 준비도 하지 않는 청소년은 **5.8%**다. 이들은 무기력감과 스마트폰 의존이 심하고, 낮은 학업 성적·부모 무관심·경제적 어려움이 겹친다.
- 제안: 진로개발역량 중심으로 관점 전환, 연계·협력 체계, 특성별 맞춤 지원, 학교 안팎 동등한 진로 지원
- 출처: [뉴스핌](https://www.newspim.com/news/view/20260408000121) (보고서 원문은 아직 확인하지 않았다)

> ⚠️ **우리 문제 정의와 일부 다르다.** 실태조사(2025)는 "진로 계획을 어떻게 세울지 모르겠다" 42.4%, 연구원(2025)은 "진로 계획을 세운 적이 있다" 69.5%다. 질문이 달라 둘 다 사실일 수 있지만(계획을 세웠어도 막막할 수 있다), **"많은 학생이 계획 세우는 법을 모른다"는 과장일 수 있다.**
> 전략에 주는 의미: 관심 찾기 퀴즈와 콘텐츠는 **넓게 막막한 학생**에게 맞고, 가장 막힌 **5.8%**는 콘텐츠만으로 닿기 어려워 센터 선생님을 통한 **사람 연결**이 필요하다.

## 2. 문제 명확화

| | 현상 1 | 현상 2 | 현상 3 |
|---|---|---|---|
| **우리가 찾은 현상** | 학업을 그만둔 뒤 **가장 큰 어려움이 진로 찾기** | 만나는 어른의 분야가 비슷해 진로 인식이 한쪽으로 쏠린다 | 지원·체험·대회는 있지만 스스로 찾지 않는 학생에게 닿지 않는다 |
| **현상의 원인** | **적성을 모르고, 진로 계획을 세우는 법을 모른다.** 관심이 없어서 막히기도 하고, 하고 싶은 게 너무 많아 고르지 못하기도 한다 | 센터 중심의 관계라 여러 분야의 현직자를 만날 기회가 적다 | 정보가 흩어져 있고, 대부분 신청해야 받는 구조다 |
| **근본 원인** | **관심을 찾고 계획을 세울 시작점이 없다** | 여러 길을 간 사람을 만날 통로가 없다 **(가설)** | 정보가 학생을 찾아가지 않고 기다린다 **(가설)** |
| **근거 수준** | ✅ 2025 실태조사 수치 | △ 한 사람의 말 | ✗ 근거 없음 |

## 3. 기존 솔루션 분석

**문제 상황**: 학교 밖 청소년이 적성을 모르고 진로 계획을 세우지 못해 막막함 속에 머무는 문제

| | 기존 솔루션 | 한계점 |
|---|---|---|
| **정부** | 꿈드림(222곳), 커리어넷(진로심리검사, 원격영상 진로멘토링), 꿈길(진로체험), 서울 원스톱서비스 | 꿈드림은 센터 상담 중심이다. 원격영상 멘토링은 학교 단위로 신청한다. 원스톱은 서울 한정이다. 검사·체험·지원 정보가 **각각 다른 곳에** 있다 |
| **기업** | 드림스폰 장학금, 기업 임직원 멘토링 CSR | 장학금은 정보 제공에 그친다. CSR은 이벤트성이라 소수만 혜택을 받는다 |
| **스타트업** | 코멘토, 달꿈 | 코멘토는 대학생 대상이다. 달꿈은 학교 수업·캠프 중심이다 |
| **NGO** | 사단법인 점프, 멘토리 | 지역·대상이 한정돼 있고, 규모를 키우기 어렵다 |

> 확인 필요: "커리어넷 검사 결과가 체험이나 지원으로 이어지지 않는다"는 아직 확인하지 않았다. 확인 전에는 발표에서 쓰지 않는다.

**최종 문제 정의**
> 학교 밖 청소년이 **자기 적성을 모르고 진로 계획을 세울 시작점이 없어** 막막함 속에 머무는 문제를, **지금 자리에서 해 볼 수 있는 것과 갈 수 있는 여러 길을 한곳에 보여 주는 지도**로 해결하고자 한다.

## 4. MISSION

**PPT용 (수치 없이)**
> __자기 적성을 모르고 진로 계획을 세울 줄 모르는 것__의 원인으로 발생하는
> __'지금 내 자리에서 무엇부터 해 볼지' 모르는__ 문제를 해결하여
> __학교 밖 청소년의 진로 찾기 어려움__ 현상을 해결해보겠습니다.

**근거 기억용 (수치 포함, 문서에만)**
> __자기 적성을 모르고(41.2%) 진로 계획을 세울 줄 모르는(42.4%) 것__의 원인으로 발생하는
> __'지금 내 자리에서 무엇부터 해 볼지' 모르는__ 문제를 해결하여
> __학교 밖 청소년의 진로 찾기 어려움(26.9%, 학업중단 후 어려움 1위)__ 현상을 해결해보겠습니다.

## 5. (선택) 우리의 해결 방법

| 근본 원인 | 우리의 해결 |
|---|---|
| 관심을 찾을 시작점이 없다 | **관심 찾기 퀴즈** → 해 볼 만한 분야 3개 (D14) |
| 계획을 세우는 법을 모른다 | 길별 **마일스톤 지도**, 이번 주 할 일 하나 (D8) |
| 직접 해 볼 기회가 적다 | 분야별 **체험**과 **대회·활동** (D8, D14) |
| 여러 길을 간 사람을 만날 통로가 없다 | **여러 길을 간 사람 이야기**, **현직자가 답하는 고민 Q&A** (D12) → 나중에 멘토 |
| 정보가 학생을 기다린다 | **인스타·쇼츠 콘텐츠**, **봉사 수업**, **센터 선생님 소개** (D7) |

## 검증 기록 (2026-09-25)

처음 정리할 때 틀린 부분이 있어 고쳤다. 다음에 이 문서를 고칠 때도 같은 확인을 거친다.

- "같이 고민해 줄 어른이 없다" → **근거 없음.** 빼고 "여러 길을 간 사람을 만날 기회가 적다"(가설)로 바꿨다.
- 2023 수치(진로 미결정 33.1%, 선입견 1위) → **2025 실태조사로 갱신**했다 (진로 찾기 1위 26.9%, 미결정 31.4%).
- "커리어넷은 학교 중심" → 틀렸다. 진로심리검사는 개인도 쓸 수 있다. 학교 단위 신청은 원격영상 진로멘토링만 해당한다.
- "학생 대부분은 수동적이다" → 근거 없음. 가설로 표시했다.
- 2025 조사를 다룬 기사 중 수치가 맞지 않는 기사가 있었다. 수치는 원문이나 주요 기사 두 곳 이상으로 확인한다.
- 논문·연구보고서 2건을 추가했다. 연구원(2025) 결과는 우리 문제 정의와 일부 다르다(69.5%가 진로 계획을 세운 적이 있음). 문제 정의를 쓸 때 과장하지 않는다.
