# 더 모을 수 있는 혜택 출처 (장학금 먼저)

> 작성일: 2026-09-27. 앞선 조사는 `docs/collection-strategy.md`, 수집기는 `crawler/README.md`.
> 목적: 지금 모으지 않는 **공식이거나 법적으로 써도 되는** 출처를 찾고, 청소년(14~24세) 항목이 몇 개 늘지, 사용자가 무엇을 신청해야 하는지 적는다.
> 표시: **[사실]**은 링크를 2026-09-27에 직접 열어 확인한 것이고, **[추정]**은 계산 근거와 함께 적은 어림값이다.
> 사용자 요청(2026-09-27): **장학금이 가장 중요한 당근이고 개수가 중요하다.** 그래서 장학금 출처를 맨 앞에 두었다. 장학금 수는 **한국장학재단 학자금지원정보 CSV(15116988 고교 1,199행 + 15028252 대학 1,913행 = 3,112행)에 없는 것**만 센다.

## 0. 먼저 알아 둘 것

- **지금 장학금이 적어 보이는 이유는 출처가 모자라서만이 아니다.** [사실] `data/collected/meta.json` 기준 장학재단 CSV에서 3,112건을 받아 2,919건을 남겼다. 하지만 그중 `open` 112건과 `upcoming` 5건만 모집 중이고 나머지 2,802건은 마감이다. 장학금은 봄(2~4월)과 가을(8~10월)에 몰려 열린다. 출처를 더 붙여도 "지금 신청할 수 있는 것"은 계절에 따라 크게 달라진다.
- **장학금만 모아 둔 공개 데이터는 사실상 장학재단 CSV 하나다.** data.go.kr에서 "장학"으로 찾은 파일데이터 212건과 "장학금"으로 찾은 오픈API 4건을 훑었다. 장학금을 한 줄에 하나씩 모집 기간과 함께 주는 곳은 장학재단 말고는 진천군(26행) 정도였다. 나머지는 통계(수혜 현황, 금액), 법인 명부, 업무 기준이다. **[사실]** 검색 결과는 [data.go.kr 검색 "장학"](https://www.data.go.kr/tcs/dss/selectDataSetList.do?keyword=%EC%9E%A5%ED%95%99)에 있다.
- 그래서 장학금 수를 늘리는 길은 셋이다. ① 이미 만들어 둔 **보조금24**(키만 남음), ② 장학재단의 **다른 두 CSV**(해외유학, 학점은행제), ③ **온통청년**의 교육·장학 정책.

## 2. 사용자가 신청할 것

모두 무료다. data.go.kr은 이미 가입한 계정을 쓴다. 발급받은 키는 저장소에 두지 말고 GitHub Secrets에 넣는다(`DATA_GO_KR_KEY`는 하나로 모든 data.go.kr API에 쓴다. 데이터셋마다 **활용신청**만 따로 한다).

1. **보조금24 키 상태 확인** (가장 급함)
   - [data.go.kr 마이페이지 → 데이터활용 → Open API → 활용신청 현황](https://www.data.go.kr/iim/api/selectAcountList.do)에서 "행정안전부_대한민국 공공서비스(혜택) 정보"가 **승인**인지 본다.
   - 목록에 없으면 [15113968 데이터셋 페이지](https://www.data.go.kr/data/15113968/openapi.do)에서 **활용신청**을 누른다. 활용목적은 "청소년 진로 혜택 안내 비영리 웹 서비스 개발", 상세 기능은 전부 체크한다. 자동승인이다 **[사실]**.
   - 승인됐는데도 수집기가 `-4 등록되지 않은 인증키`로 실패하면(2026-09-27 `meta.json`에 있음) 두 가지를 확인한다. ① 승인 뒤 게이트웨이 반영에 1~2시간이 걸릴 수 있다 [추정]. ② GitHub Secret에 **Decoding 키**(일반 인증키, `%` 없는 것)를 넣었는지.
2. **청소년활동 방학 중 프로그램**: [15073963](https://www.data.go.kr/data/15073963/openapi.do) → **활용신청** (자동승인, 개발 1만 건/일 **[사실]**)
3. **청소년활동 공공기관 프로그램**: [15067705](https://www.data.go.kr/data/15067705/openapi.do) → **활용신청** (자동승인 **[사실]**)
4. **청소년 국제교류 프로그램**: [15073960](https://www.data.go.kr/data/15073960/openapi.do) → **활용신청** (자동승인 **[사실]**)
5. **온통청년 오픈API 키** (data.go.kr과 **별개**. 따로 가입해야 한다)
   - [온통청년](https://www.youthcenter.go.kr)에서 **회원가입** → 로그인
   - **마이페이지 → 오픈(OPEN) API**에서 **인증키 발급 신청**을 누른다. 신청 내용에는 서비스 설명과 이용 목적을 적는다("청소년·청년 진로 혜택 안내 비영리 서비스, 정책 목록 조회"). **담당자 심사 후 승인**되고, 부적절하면 미승인될 수 있다 **[사실]** ([이용방법](https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiGuide)).
   - 발급된 키는 GitHub Secret `YOUTHCENTER_API_KEY`로 넣는다(이름은 제안이다).
   - 참고: data.go.kr에도 [15143273 온통청년 청년정책API](https://www.data.go.kr/data/15143273/openapi.do)가 있다. 하지만 유형이 **LINK**라 결국 온통청년 키가 필요하다 **[사실]**.

7. **문화예술교육 자원지도**: [15140200](https://www.data.go.kr/data/15140200/openapi.do) → **활용신청** (자동승인, 개발 1천 건/일 **[사실]**)

### 3.1 보조금24 = 대한민국 공공서비스(혜택) 정보 (행정안전부)

- URL: <https://www.data.go.kr/data/15113968/openapi.do>. 운영: 행정안전부.
- 접근: Open API, 자동승인, 개발계정 1만 건/일 **[사실]**. 이용허락범위 제한 없음 **[사실]**.
- 갱신: 수시(수정일시 제공). 대상 필드: 대상연령 시작/종료(JA0110/JA0111), 중·고·대학생 코드 **[사실, collection-strategy.md]**.
- 상태: `crawler/sources/gov24.py`가 이미 있고 장학·학자금 키워드(`SCHOLARSHIP`)도 들어 있다. 2026-09-27 실행은 키 오류(`-4 등록되지 않은 인증키`)로 0건이었다 **[사실, meta.json]**.
